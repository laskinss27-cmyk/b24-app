Переписки Telegram

Ваш обычный аккаунт → два клиентских диалога → пробная привязка к карточке.

Привязки в этой пробе хранятся до закрытия сервера. Рабочие карточки ещё не обновляются.

Вход с тестовыми параметрами Telegram. Проверяем только два выбранных диалога. Этот режим не предназначен для постоянной работы.

1. Подключите Telegram для пробы

Можно попробовать вход по QR-коду с официальными тестовыми параметрами Telegram.

Подходит для одной локальной пробы двух диалогов. Тестовый доступ ограничен Telegram и может не сработать. Для постоянной работы понадобится своё API-приложение.

У меня есть собственные API-параметры

Для прямого подключения Telegram нужны два параметра приложения. Их выдаёт сам Telegram.

  1. Откройте my.telegram.org/apps и войдите по рабочему номеру.
  2. Если приложения ещё нет, создайте его: название B24 Telegram Pilot, короткое имя b24pilot, платформа Desktop.
  3. Скопируйте api_id и api_hash в поля ниже. Затем появится QR-код для входа.

Параметры и пароль вводите здесь. Отправлять их в чат не нужно.

Подключение создаёт дополнительную сессию вашего аккаунта. В этой пробе загружаем сообщения только выбранных диалогов; сессия технически имеет доступ к аккаунту. Отправка сообщений и отметка прочтения не выполняются.

2. Подключите рабочий аккаунт

В Telegram на телефоне: Настройки → Устройства → Подключить устройство. Отсканируйте этот код.

QR-код обновляется автоматически.

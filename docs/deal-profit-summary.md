# Общая плашка прибыли товаров

Решение пользователя 01.10.2026: убрать плашку прибыли услуг, объединить фактическую и плановую прибыль в одну понятную плашку. Прежняя отдельная оценка услуг в шапке сделки снята по этому решению, а не потеряна при восстановлении. Данные не мигрируются.

Шапка «Товары сделки» содержит три прежних суммы и одну плашку «Прибыль товаров» с двумя строками:

- **Факт** — существующий goodsProfit: выручка проведённых реализаций минус возвраты и знаковая себестоимость складских проводок. Расчёт FIFO и исторические значения не меняются.
- **План · оценка** — существующая товарная часть предварительного расчёта (продажная стоимость минус закупочная по строкам состава, с прежними правилами этапов/выбранного КП). Прибыль работ здесь не добавляется: факт и план сравнивают только товары. Прежний суммарный предварительный profitability остаётся совместимым для других потребителей; backend/reporting API и оценки услуг в отчётах не меняются.

Исключение расходников из прибыли сохраняется. Суммы товаров, работ и всей сделки прежние. Общая плашка объединяет отображение, а не складывает факт с планом: фактическое значение может относиться к частично отгруженному составу. Подпись «Реализации минус возвраты» и «План · оценка» объясняют базу расчёта.

При неполных фактических проводках — прочерк и число строк без данных; при недоступном расчёте и отсутствии проведённых реализаций — разные пояснения. Нулевая известная прибыль показывается как 0 ₽, отрицательная — со знаком. Неполный план показывается с ≈ и явным количеством строк без закупки; если закупка неизвестна у всех товарных строк, вместо выдуманного нуля — прочерк. В альтернативном КП факт по-прежнему не показывается: он относится к действующей сделке, а не альтернативе.

Реализация: `DealProductsSummary.tsx`, `DealProductsWorkspace.tsx`, `deal-products-table-view.ts`, `deal-products.css`; тема обновляется штатным генератором. Семантический dl сохраняет пары подписей и значений. На узком экране общая сумма и прибыль занимают полную ширину; крупный текст и длинные суммы переносятся без обрезания.

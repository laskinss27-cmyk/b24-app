## Как найти реализацию

Исторические пути: packages/backend/src/inventory-export.ts, inventory-xlsx.ts, routes/api-inventory-export-route.ts; packages/frontend/src/InventoryExportButton.tsx, inventory-export.ts. Проверки: inventory-xlsx.test.ts, routes/api-inventory-export-route.test.ts, frontend inventory-export.test.tsx.

```sh
git show 378eb83:packages/backend/src/inventory-export.ts
git show 378eb83:packages/backend/src/routes/api-inventory-export-route.ts
git log --all --oneline -- packages/backend/src/inventory-xlsx.ts
```

Если коммита нет в локальном clone, получить соответствующую ветку из origin; исходная ветка codex/inventory-excel-export. Более поздний исторический снимок и перечень отсутствующих путей зафиксированы в [JSON аудита](audits/2026-09-29-source-comparison.json).

Экспорт должен использовать сохранённые факты и основание подсчёта, а не незаметно заменять их текущим остатком. Нужны проверки всей ревизии/одного склада, сохранности фактов, денежной базы, прав доступа и корректности XLSX. Сначала согласовать INV-04 и учитывать INV-06.

Старую миграцию 0113 нельзя запускать автоматически: текущая инвентаризация использует Bitrix entity ctv_inv, а историческая реализация содержала SQL-слой. Перенос требует адаптации к действующему хранилищу и проверки на копии данных. Игнорируемые папки outputs не являются обязательной зависимостью документации.

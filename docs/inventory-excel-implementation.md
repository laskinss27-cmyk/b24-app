## Поведение

В раскрытых деталях инвентаризации доступны «Скачать Excel» для всей ревизии и «Excel склада» для отдельной точки. Файл содержит листы «Сводка» и «Товары», сведения о ревизии, складе и состоянии подсчёта, учётное количество, факт, разницу и комментарии. Не введённый факт остаётся пустым; явно введённый ноль сохраняется нулём. Добавленный при подсчёте товар имеет нулевой учётный остаток.

Денежные колонки используют сохранённую закупочную цену `purchase` результата, соответствуя нынешней базе UI. В сводке показаны недостача, излишки и итог; есть строка «Всего». Если цены недостаточно, денежный итог остаётся пустым с пояснением. Текущий прайс не подставляется. Историческая розничная оценка `77a0663` не возвращалась: открытое расхождение INV-04 сохранено отдельно.

Экспорт читает `DETAIL_TEXT` текущей Bitrix entity `ctv_inv`: зафиксированный `stockSnapshot`, черновик/результат и комментарии. ERP используется только для справочных названий и единиц товаров, не для подмены сохранённых остатков или цен. Повреждённый снимок отклоняется. Экспорт не записывает данные и не проводит документы.

Покрыты вся ревизия/склад, снимки, пустой факт/ноль, добавленные товары, комментарии, деньги и отсутствие цены, авторизация и скачивание. Кнопки также проверены в локальном интерфейсе.

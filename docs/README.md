## Главные факты

- Прод: `https://201.51.12.57.sslip.io`.
- Backend: контейнер `b24-backend`, локальный порт хоста `127.0.0.1:3000`.
- ERPNext: стек Docker Compose в `/root/erpnext`, локальный порт хоста `127.0.0.1:8080`.
- Код на сервере: `/root/b24-app-git`.
- Секреты: `/root/erpnext/backend.env` и `/root/sync/.env`; в Git их нет.
- ERPNext — источник складских остатков и документов.
- Битрикс24 — источник CRM-сущностей.
- Бэкап ядра запускается ежедневно в 15:00 по Москве.

## Правило актуальности

Если изменение меняет экран, маршрут, размещение, переменную окружения, источник данных или процедуру деплоя, связанный документ обновляется в том же коммите. Неподтверждённые планы помечаются как планы и не описываются как готовая функция.

# Выгрузка инвентаризации в Excel

В списке инвентаризаций кнопка «Скачать Excel» выгружает все склады выбранной ревизии. Кнопка «Excel склада» в строке точки выгружает только её. Доступ соответствует просмотру инвентаризации.

Файл XLSX содержит листы «Сводка» и «Товары»: склад, ответственный, статус, время снимка, ID и наименование товара, артикул, учётное количество, факт, расхождение и комментарий. Числа хранятся числами, ID и артикулы — текстом. Заголовки закреплены, включены фильтры. Недостачи и излишки выделены цветом.

Выгружаются только сохранённые сервером данные. Перед выгрузкой завершите автосохранение подсчёта и вернитесь к списку инвентаризаций. Отправлять отчёт или проводить документы для выгрузки не нужно. Скрытые поиском строки не исключаются.

Учёт берётся из неизменяемого снимка ревизии. Для старых ревизий без снимка используются лишь сохранённые строки, неизвестный учёт остаётся пустым. Факты прежнего раунда, которые не сохранились по товарам, не восстанавливаются предположениями; ограничение указано в сводке. Названия недостающих товаров и артикулы читаются из текущих карточек ERPNext через API. Остатки Bin при выгрузке не читаются.

POST `/api/inventory/export-xlsx`: авторизация как у остальных маршрутов инвентаризации, `inventoryId` и необязательный `storeId`. Проверяется пользователь через `user.current`, в том числе при SQL-primary. Экспорт не вызывает запись, проведение документов, создание сущностей или доставку отложенных Bitrix-зеркал.

Изменение подготовлено в отдельной рабочей копии от production-коммита `7c19896`. Выкладка требует отдельного подтверждения.

## Проверки

- `npm run test:inventory-export --workspaces --if-present`: создание и повторное чтение XLSX, нули и пустые ячейки, дробные количества, старые ревизии и акт, фильтрация склада, авторизация, MIME, имена файлов и обработка ошибок.
- `npm test --workspaces --if-present`: общие регрессионные тесты backend и frontend прошли. Тест хранилища подтверждает отсутствие доставки отложенных зеркал при экспорте SQL-primary.
- `npm run build`: сборка backend и frontend прошла.
- Локальный браузер: «Складской учёт → Инвентаризация», обе кнопки видны, макет проверен, ошибка отсутствия авторизации отображается рядом с кнопкой. Авторизованная выдача XLSX проверена через Fastify inject с тестовыми источниками, не на production.

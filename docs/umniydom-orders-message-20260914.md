## Неопределённая отправка и откат

Для новых сообщений квитанция больше не печатается в чате. При неопределённом
результате искать сообщение по номеру заказа, затем сверять сохранённый полный
`notification_plan`, покупателя, время и часть. Одного номера недостаточно.
Receipt, message IDs и план остаются в SQLite. Не выполнять слепой resend.
Старые планы и сообщения не переписывались; у старых сообщений квитанция остаётся.

Откат: после проверки отсутствия обработки и краткой остановки мониторинга вернуть
сохранённый `worker.production.before.yaml` на место override и пересоздать только
worker штатной compose-командой с `--no-deps`; включить мониторинг и проверить.
Не восстанавливать SQLite поверх рабочей базы: это может повторить уже выполненные
действия. Старый образ сохранён. Не запускать activate-worker повторно.

Accuracy lives here:
one stock value, transaction-backed, with no divergence between systems.
Why there is no “synchronisation hell”: stock is one value and it lives only in the inventory system. Bitrix24 does not copy it; it queries and displays it live. The systems exchange commands and events (“write off”, “receive”), not two separate stock values that must later be reconciled. Every data type has one owner.

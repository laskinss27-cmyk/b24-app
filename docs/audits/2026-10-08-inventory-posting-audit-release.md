## Границы

UI проверен SSR-регрессиями и наличием подписей в опубликованной сборке. Реальное проведение через браузер от сотрудника ради проверки не выполнялось: нельзя создавать складское движение для технического теста. Время аудита — время запроса сервером перед ERP-транзакцией; интерфейс отображает МСК. Прямые проведения из ERPNext не получают личность Битрикс24. Исторического автора восстановить по этим новым полям невозможно.

## Ограничения и следующий релиз

Новые функции ещё не проверены на реальном Telegram-вложении и реальном отзыве рабочей сессии. Отправку в общий чат на production намеренно не имитировали. WhatsApp — только прежний личный локальный пилот, в эти оповещения не включён. Криптографическое стирание RAM/OS swap не обещается. Внешнее сохранение файла средствами браузера приложение не контролирует.

Добавлен закреплённый `pdfjs-dist 6.4.299`, worker поставляется со сборкой, без CDN. Проверка npm audit не показывает advisory для PDF.js/его новых зависимостей; в общем дереве есть прежние предупреждения других пакетов, это не отчёт о полной безопасности зависимостей.

Перед production повторить требования AGENTS.md: сверка реестра/деплойного SHA, чистый pushed checkout, штатная сборка и source guard, backup SQLite, точный candidate, сохранение rollback, сеть ERP и обязательные health/ERP/retention проверки. Не использовать этот локальный отчёт как разрешение обойти release guard. Старый бинарник не понимает историю имён; особенности отката описаны в контракте.

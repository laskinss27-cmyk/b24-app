## Проверки

- Полные штатные тесты: **354 backend + 170 frontend = 524**, все проходят, пропусков нет.
- Проверки релизного инструментария: **6/6**.
- `npm run build` и `npm run typecheck`: успешны. Vite сообщает обычное предупреждение о размере основного JS chunk; ошибки сборки нет.
- `node scripts/audit-returned-history.mjs`: 2/2; `node scripts/audit-route-guards.mjs`: 10/10. Это выборки из штатного набора, не дополнительные 12 уникальных тестов. Скрипты больше не создают временные исходники.
- Локальный браузер: кнопки Excel всей ревизии и склада; форма заявки блокирует создание с пустым общим комментарием и разблокирует после заполнения. Форма проверена на локальных данных без отправки заявки.

Восстановленные тесты находятся в обычных `src/**/*.test.ts(x)` и автоматически запускаются локально и при сборке релиза. Пути к коду и проверкам записаны напротив постоянных ID в [реестре](../feature-registry.md). В описании прав исправлена документационная ошибка: действующая константа `SUPPLY_DEPARTMENT_ID` равна 10; сами права не менялись.

## Что этим изменением не подтверждено

Историческое расхождение розничной и нынешней закупочной оценки (INV-04), проверки актуальности и движений перед проведением инвентаризации (INV-06), а также прочие ограничения исходного аудита остаются открытыми. Денежные блоки UI присутствуют, что пользователь подтвердил отдельно; они не считались утратой. Excel использует сохранённую закупочную оценку и не меняет формулы UI или текущий прайс.

Тесты выполнялись на подменах данных; сквозные операции и миграции на production не запускались. Для выкладки остаётся обязательным штатный процесс из [release-provenance](../release-provenance.md) и AGENTS.md. Найти коммит этого восстановления: `git log --all --oneline -- docs/audits/2026-09-29-feature-restoration.md`.

Полные локальные suites: 652 backend / 214 frontend / 8 release, без fail/skip. Базовая версия каталога: 629 / 212 / 8; добавлены 23 backend и 2 frontend сценария, discovery не менялась. Browser сценарий общего экрана прошёл, включая QR WhatsApp, раздельные namespace history/media, 360/768/1280, keyboard, отсутствие XSS, отмену/очистку media и прежние Telegram-группы/исторические имена.
